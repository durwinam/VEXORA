# Installation notes

Recommended one-line installer:

`curl -fsSL https://raw.githubusercontent.com/durwinam/VEXORA/main/install.sh -o /tmp/vexora-install.sh && sudo bash /tmp/vexora-install.sh`

Do not pipe a mutable remote script directly to a shell when you need a reviewable installation flow. The two-step command downloads it first, then executes the local copy.
